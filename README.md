# Vaibhav Chopra — Resume

Private source for Vaibhav Chopra's interactive web resume.

## Preview locally

```sh
python3 -m http.server 8765
```

Then open [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

The page is a standalone HTML document with a responsive layout, a progressively enhanced WebGL hero, reduced-motion and high-contrast fallbacks, and a one-page print stylesheet.
